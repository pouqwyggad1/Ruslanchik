# Лабораторная работа №1: Автоматизация браузера и работы с документами

## Описание работы

Проект реализует автоматизированного робота для сбора данных с сайта [dns-shop.ru](https://www.dns-shop.ru/) и формирования аналитического отчета в формате `.xlsx` (Excel).

Скрипт решает проблему защиты от ботов сайта DNS-shop с помощью библиотеки `undetected-chromedriver`, которая маскирует браузерную сессию под реального пользователя и скрывает признаки автоматизации Selenium (`navigator.webdriver`).

---

## Выполненные требования задания

### Часть 1 (Selenium):
1. **Поиск товаров**: Робот открывает `https://www.dns-shop.ru/` и через строку поиска ищет заданный набор товаров (по умолчанию `мышь`).
2. **Сортировка**: Изменяет сортировку каталога на **«По количеству отзывов»**.
3. **Добавление в избранное**: Находит самый дешевый товар среди результатов первой страницы и кликает кнопку «Добавить в избранное».
4. **Переход в избранное**: Переходит на вкладку «Избранное» и останавливает работу робота без закрытия окна браузера (ожидает ввода `Enter` от пользователя).

### Часть 2 (Openpyxl):
1. **Формат таблицы**: Ранее найденные товары выгружаются в файл `products.xlsx` со столбцами:
   - `Название`
   - `Цена`
   - `Рейтинг`
   - `Статус`
2. **Оформление шапки**: Шапка таблицы залита цветом (`#366092`), текст белый жирный, выравнивание по центру.
3. **Сортировка и автофильтр**: Таблица отсортирована по названию в алфавитном порядке, включен фильтр Excel (`AutoFilter`).
4. **Формула MIN**: Непосредственно под последней ячейкой столбца «Цена» добавлена формула `=MIN(B2:B{N})`.
5. **Условное форматирование «Рейтинг»**:
   - Значение $\ge 4.8$ — зеленый цвет (светло-зеленый фон, темно-зеленый текст).
   - Значение $< 4.8$ — красный цвет (светло-красный фон, темно-красный текст).
6. **Условное форматирование и валидация «Статус»**:
   - Товар, добавленный в избранное (самый дешевый), имеет статус `+` (зеленый цвет).
   - Остальные товары имеют статус `-` (красный цвет).
   - Настроена проверка данных (`DataValidation`) с выпадающим списком: разрешен выбор только значений `+` или `-`.

## Установка и запуск

### 1. Установка зависимостей
```bash
# Активация виртуального окружения (если используется Windows PowerShell)
.venv\Scripts\Activate.ps1

# Или установка в текущее окружение:
pip install -r requirements.txt
```

### 2. Запуск программы
```bash
# Стандартный запуск (поиск по категории 'мышь')
python main.py

# Или запуск с указанием своего поискового запроса:
python main.py наушники
```

После выполнения всех действий будет создан файл `products.xlsx`, а браузер останется открытым на странице избранного. Для выхода нажмите `Enter` в окне терминала.
